# phone-approvals

When a handoff is waiting for my approval, today I only see it in the desktop
dashboard. I want it on my phone: in the forge's space, in an approvals room, a
message that tells me which project and card it belongs to, which gate it is
(who is handing what to whom), and what changed — enough to decide without
opening the laptop. I want to approve it from the phone by reacting to that
message, and to send it back with feedback by replying in its thread, with the
same effect the desktop dashboard has and nothing else able to act as me. Once
something is resolved — from the phone or from the desktop — the room should
show that, so I never approve the same thing twice. Deleting work and tearing
projects down stay on the desktop.
