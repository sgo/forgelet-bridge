# forge-display-names

Every message the bridge posts reads "Bridge" on my phone, whichever forge it
came from, so with more than one forge I cannot tell them apart. I want the
sender to read "Forgelet" in Forgelet's rooms and "Saibill" in Saibill's, and
the space to carry that same name instead of the directory name. The name should
be something I configure per forge rather than derived from the folder — `sgo`
would never yield "Saibill".
